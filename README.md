CNR Design Studio

CNR Design Studio is a web platform built for an individual architect to visualize architectural concepts and bring designs to life. It serves as the architect's online studio, where clients can explore previous works and completed projects, view design concepts, and book appointments with the architect directly through the platform.

This project was developed for the module EC4307 – Web Application Development at the Faculty of Engineering, University of Ruhuna, using React for the frontend, Spring Boot for the backend and MySQL for the database.
